# Semantic Encoding Feature Codes

This is the position-coded feature table used one level deeper than Phase 1 -- for the `semantic_encoding` stage that Phase 1 text eventually feeds into. Phase 1 encoding itself does not use these single-letter codes directly, but this is useful background for understanding what a given Phase 1 choice will resolve to downstream, and for interpreting the `Sources_2026-07-27_tabitha.sqlite` project file if you need to cross-reference a semantic_encoding value.

Source: the `Features` table of the project's `Sources_2026-07-27_tabitha.sqlite` file (877 rows), exported here as a static reference so it does not need to be re-queried each time.
